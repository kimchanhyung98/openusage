# 활성화되는 프로바이더

첫 설치와 업데이트에서 프로바이더가 자동 활성화되는 조건.
업데이트는 사용자가 저장한 기존 프로바이더의 켜기·끄기 설정 유지.

## 첫 설치

새로 설치한 앱은 OpenUsage가 아는 프로바이더를 전부 켜지 않음.
Claude와 Codex를 활성화한 뒤 Mac의 로컬 인증 정보·사용 흔적 확인.
기존 로그인, 저장된 API 키, 지원하는 환경 변수, 로컬 사용 이력 등 프로바이더별 감지 조건 적용.
도구의 설치 여부만으로 활성화를 결정하지 않음.
각 프로바이더의 감지를 동시에 시작하며, 감지 과정에서는 네트워크 요청 없음.
감지 결과가 있고 활성 목록이 초기 Claude/Codex 조합이면 감지된 프로바이더 조합으로 변경.
감지 중 사용자가 다른 활성 조합을 선택했다면 해당 목록 유지.
아무것도 찾지 못하면 Claude/Codex 시작 세트를 그대로 유지.
감지로 활성화한 프로바이더는 다음 예약 주기를 기다리지 않고 조회 시작.
조회에 성공하면 사용량 표시.
인증 정보 접근이나 조회에 실패하면 오류 안내.
이미 등록한 Claude 계정의 저장 로그인은 Keychain 확인이 일시적으로 불가능해도 탐지 대상 유지.
등록 계정의 카드도 확인 불가만으로 숨기지 않으며, 실제 사용량 조회에서 인증 접근 실패 안내.
미등록 로그인은 확인된 인증 흔적이 있어야 자동 탐지.
접근 문제로 누락됐다면 Customize에서 직접 켜기 가능.
대시보드가 이를 어떻게 보여 주는지는 [대시보드 § 첫 실행](/docs/dashboard.md#첫-실행) 참조.

## 업데이트로 새 프로바이더가 추가될 때

업데이트 후 첫 실행에서 OpenUsage는 지금 앱에 포함된 프로바이더와 이 설치가 전에 본 프로바이더를 비교.
처음 보는 프로바이더마다 같은 로컬 감지 수행:

- **로컬 인증 정보·사용 흔적 감지** → 프로바이더 활성화.
- **감지 결과 없음** → 꺼진 상태 유지.
  나중에 **Customize**(사용자 지정)에서 켜기 가능.

이 확인은 **프로바이더당 한 번**만 일어남.
이후 업데이트에서는 같은 프로바이더를 다시 감지하지 않음.
나중에 로그인하거나 도구를 설치한 경우 Customize에서 직접 켜기.

## 기존 설정 유지와 초기화

업데이트는 Customize의 기존 프로바이더 켜기·끄기 설정, 지표 레이아웃, 메뉴 막대 별표 유지.
자동 활성화 대상은 이번 설치에서 처음 보는 프로바이더로 제한.
해당 프로바이더의 로컬 인증 정보·사용 흔적이 감지된 경우에만 자동 활성화.

Customize 프로바이더 목록 상단의 **Reset All Customization**(모든 사용자 지정 초기화)은 기존 설정을 초기화하는 사용자 동작.
실행 전에 확인 요청.
확인하면 첫 실행과 같은 로컬 감지를 다시 수행해 활성 프로바이더 결정.
감지 결과가 없으면 Claude와 Codex 활성화.
이 과정에서 켜 둔 프로바이더가 꺼지거나, 꺼 둔 프로바이더가 켜질 수 있음.
지표 설정의 초기화 범위는 [대시보드](/docs/dashboard.md) 참조.

## 상태 확인과 활성화

공식 서버 상태 확인에는 활성화된 프로바이더만 참여.
현재 Claude, Codex, Cursor, Copilot에 명시적인 상태 소스가 있으며, 상태 소스가 없는 활성 프로바이더는 상태 요청을 보내지 않음.
Claude와 Codex 계정 카드는 계정별로 요청하지 않고 프로바이더 패밀리의 상태 결과 하나를 공유.
이 공개 확인은 로컬 인증 정보 감지와 분리되어 있고 인증을 사용하지 않으며, 프로바이더를 활성화한 인증 정보를 전송하지 않음.

## 감지 대상 기록

앱은 활성화와 신규 감지 여부를 판단하기 위해 두 목록 사용:

- **활성화된 프로바이더** — 현재 켜져 있는 프로바이더.
  대시보드와 메뉴 막대가 읽는 기준.
- **알려진 프로바이더** — 이 설치가 지금까지 본 모든 프로바이더.
  알려진 목록에 있는 프로바이더는 활성 여부와 관계없이 신규 감지 대상에서 제외.
  처음 보는 프로바이더는 감지를 시작하기 전에 알려진 목록에 기록.

각 프로바이더의 `hasLocalCredentials()`가 로컬 감지 수행.
일반 새로 고침과 같은 파일, Keychain 항목, 저장된 키, 환경 변수 또는 로컬 사용 이력을 확인.
이 감지 과정은 네트워크 요청 없이 수행.

(첫 실행 감지가 생기기 전의) 오래된 설치는 모든 프로바이더가 켜진 상태로 시작하고 *꺼진* 것만 저장했음.
일회성 설정 변환으로 기존 켜기·끄기 상태를 보존하고 위 목록들로 전환.
변환 후에는 같은 신규 프로바이더 감지 적용.
