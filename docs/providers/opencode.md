# OpenCode

> 2026-10-28 확인: 아래 Go 상한은 기존 방식의 추정치이며, 현재 Go·Go Plus의 모델별 allowance와 다를 수 있음.
> 새 구독의 정확한 잔여량이나 Plus 등급 판정에는 사용 불가.
> 최신 요금과 로컬 기록 제약은 [가격 조사 기록](/docs/research/pricing-2026-10-28.md)의 OpenCode 항목 참조.

Mac에 이미 저장된 OpenCode 자체 로그를 사용해 OpenCode 호스팅 사용량(**Go** 구독과 **Zen** 종량제 게이트웨이) 추적.
원본 로그는 이 Mac에서만 읽음.

## 추적 항목

| 지표 | 의미 |
|---|---|
| Session | 최근 5시간의 로컬 Go 사용액과 $12 상한 |
| Weekly | 이번 주의 로컬 Go 사용액과 $30 상한(UTC 월요일 시작) |
| Monthly | 로컬 기록으로 정한 월간 기간의 Go 사용액과 $60 상한 |
| Today / Yesterday / Last 30 Days | 모든 OpenCode 호스팅 사용량(Go + Zen)의 로컬 비용과 토큰 |
| Usage Trend | 최근 한 달간 토큰의 일별 스파크라인 |

로컬 Go 키 또는 지출·Go 집계 범위 안의 Go 기록이 있으면 프로바이더 이름 옆에 "Go" 표시.
서버에서 실제 구독의 활성·만료 여부를 확인하지 않음.

Session / Weekly / Monthly 미터는 **로컬에서 관측한 사용액**, 즉 *이* Mac에 기록된 사용량을 표시.
다른 기기의 사용량이나 아직 저장되지 않은 기록은 포함하지 않음.
미터와 재설정 시각은 이전 Go 방식의 로컬 추정값이며, 현재 계정의 실제 잔여 allowance와 다를 수 있음.
로컬 Go 키와 집계 범위 안의 Go 기록이 모두 없으면 Go 상한 미터 미표시.
Zen 사용 기록은 지출 타일에 계속 반영.

## 인증 정보 출처

평소처럼 OpenCode 사용.
로컬 데이터 디렉터리의 `auth.json`에서 Go 키 확인.
사용액과 토큰 수는 같은 디렉터리의 SQLite 로그에서 계산.
데이터 디렉터리는 다음 순서로 결정:

1. `OPENCODE_DATA_DIR`이 설정돼 있으면 해당 경로 사용.
2. 그 외에 `XDG_DATA_HOME`이 설정돼 있으면 `$XDG_DATA_HOME/opencode` 사용.
3. 두 환경 변수가 모두 없으면 `~/.local/share/opencode` 사용.

로그인 프롬프트나 붙여 넣을 토큰 불필요.

## 미터와 지출 타일

달러 금액은 OpenCode가 로컬 메시지에 기록한 비용을 다시 계산하지 않고 합산.
OpenCode 버전에 따라 기록값 자체가 카탈로그 단가로 계산한 추정 비용일 수 있으며, 실제 청구액·Go allowance와 다를 수 있음.
각 지출 타일은 Claude / Codex / Cursor와 동일하게 비용과 토큰을 함께 표시(`$4.08 · 1.2M tokens`).
검사 범위는 지출 타일보다 넓은 월간 Go 기간까지 포함.
현재 지출 타일과 Go 기간에 속하지 않는 과거 기록은 비용 합산에서 제외.
Zen 기록은 지출 타일 기간에만 반영.
큰 유한 비용은 반올림 과정에서도 그대로 유지해 사용량 스냅샷 저장 가능.
지출 타일은 해당 기간에 사용 기록이 없으면 "No data" 표시.
Go 키가 있고 사용 기록이 없으면 상한 미터에는 $0 표시.
합산 가능한 숫자 범위를 넘기는 비용 행은 지출 타일·추세·Go 사용량에서 함께 제외하고 불완전 이력 안내 표시.
나머지 정상 행은 계속 반영.
원본 로그는 이 Mac에서만 읽음.

현재 OpenUsage가 적용하는 이전 Go 상한은 **5시간당 $12**, **주당 $30**, **월당 $60**.
계정별 한도를 서버에서 조회하지 않음.

- **Session:** 최근 5시간의 기록 합산.
  사용 기록이 있으면 카운트다운은 가장 오래된 기록이 집계에서 빠지는 시각.
  이후 기록이 남아 있으면 그 시각에도 사용액이 0보다 클 수 있음.
- **Weekly:** UTC 월요일부터 다음 월요일까지의 기록 합산.
- **Monthly:** 이 Mac에서 읽은 가장 이른 Go 기록의 UTC 날짜·시각으로 월간 경계 계산.
  해당 날짜가 없는 달에는 그 달의 마지막 날짜 사용.
  최초 Go 기록을 확인하지 못하면 UTC 기준 매월 1일부터 집계.

Zen 사용량은 Go 상한 계산에서 제외하고 지출 타일에만 반영.

## 문제 해결

- **모든 항목에 "No data" 표시** — `~/.local/share/opencode/opencode*.db`의 OpenCode 로컬 데이터베이스 필요.
  OpenCode 세션을 실행한 뒤 새로 고침.
  (Go에 로그인된 경우 첫 로컬 메시지 전에도 상한 미터에 $0 표시.)
- **Session / Weekly / Monthly 미터가 없음** — 로컬 Go 키나 지출·Go 집계 범위 안의 Go 기록이 있는지 확인.
  집계 범위 밖의 과거 기록만으로는 상한 미터가 나타나지 않음.
  키나 집계 범위 안의 기록이 남아 있으면 구독 만료 후에도 미터가 나타날 수 있음.
- **"Couldn't read OpenCode's local database"** — 데이터베이스(또는 데이터 디렉터리)가 있지만 이번 새로 고침에서 읽지 못한 상태.
  OpenCode를 종료하고 새로 고침한 뒤에도 문제가 계속되면 `~/.local/share/opencode` 권한 확인.
- **"Couldn't read OpenCode's auth.json"** — 파일이 있지만 읽을 수 없거나 유효한 JSON이 아닌 상태.
  권한을 확인하거나 OpenCode Go에 다시 로그인해 파일 재작성.
- **수치가 대시보드보다 낮음** — 미터는 로컬에서 관측한 사용액(이 Mac만 해당)으로, 위 설명 참고.

## 내부 동작

데이터 디렉터리의 모든 `opencode*.db`에서 어시스턴트 메시지의 `cost`와 토큰 필드를 읽는 방식(OpenCode는 릴리스 채널별로 데이터베이스 분할 — stable은 `opencode.db`, preview는 `opencode-next.db` — 모든 채널 합산).
Go 상한에는 `opencode-go` 메시지를 합산하고, 지출 타일과 추세에는 `opencode-go`(Go)와 `opencode`(Zen)를 모두 합산.
읽기 전용, 네트워크 미사용.
공식 사용량 API 연동은 미구현.
