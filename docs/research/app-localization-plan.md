# 앱 다국어 지원 계획

이슈 #108의 한국어 지원 요청과 소유자가 확정한 영어·한국어·일본어 지원 범위를 기록.
기존 `main` 작업과 실행 중인 앱에 영향을 주지 않도록 별도 워크트리의 `feat/app-localization`에서 구현.
현재 동작은 [설정](/docs/settings.md#일반), 구현 구조는 [아키텍처](/docs/architecture.md#표시-언어) 참조.

## 확정 요구사항

| 항목 | 결정 |
|---|---|
| 설정 위치 | General의 Global Shortcut 아래 Language 선택 항목 |
| 지원 언어 | English·한국어·日本語 |
| 최초 실행 | 저장된 앱 언어가 없으면 항상 English |
| 언어 선택 | 사용자 선택만 사용하며 시스템 언어 자동 탐지 없음 |
| 적용 시점 | 앱 종료 후 다음 실행부터 적용 |
| 변경 안내 | 현재 실행 언어와 선택이 다르면 재시작 안내 표시 |
| 설정 범위 | 앱 전용 선택값만 저장하며 macOS 전체 언어 설정 유지 |

## 구현 범위

- 대시보드·Customize·설정·계정 관리·상세 화면의 표시 문구.
- 메뉴·접근성 설명·알림·공유 이미지·앱이 정의한 오류와 경고.
- 날짜·남은 시간·단위 문구의 언어별 표시.
- 7개 번역 테이블에 언어별 708개 키 등록.
- 개발·배포 패키지의 번역 리소스 포함과 지원 언어 선언.
- 사이트 설정 미리보기의 Language 항목·선택 저장·안내.
  미리보기 자체는 영어를 유지하며 한국어·일본어 앱 화면을 재현하지 않음.

자동 언어 감지·실행 중 언어 전환·자동 재시작·통화 환산은 범위 밖.
사용자 계정명·공급자명·모델명·외부 명령 출력은 원문 유지.
USD와 K/M/B 수치 축약, 사용량 계산, 지표 기본 배치는 기존 정책 유지.

## 역할 분담

| 위치 | 책임 |
|---|---|
| `LanguageSetting` | 앱 언어 선택 저장과 실행 시 언어 확정 |
| `OpenUsageMain` | SwiftUI·AppKit 초기화 전에 언어 적용 |
| `L10n` | 선택 언어의 테이블 조회와 문장 인자 포맷 |
| `LocalizedMessage`·`UserPresentableError` | 오류·경고 원문과 번역 키·인자 분리 |
| 화면·포맷터 | 표시 시점에 제목·문장·날짜 변환 |
| CLI·HTTP 직렬화 | 기존 필드·식별자·단위·오류 원문 유지. 레거시 `/v1/usage` 차트 날짜 `label`은 생성 시점 locale로 표시 |

번역 파일은 SwiftPM 기본 리소스 처리로 배포하며 별도 생성기나 의존성 추가 없음.
언어 초기화는 프로세스의 임시 설정만 사용하므로 첫 설치 판별에 필요한 영속 설정 상태 유지.
언어별 테스트는 `L10n.withLanguage`와 독립 설정 저장소로 실행해 사용자 설정 변경 방지.

## 호환성

프로바이더·위젯 ID, 지표 조회 라벨, 설정 raw value는 번역하지 않음.
캐시의 표시 정보는 선택적 필드로 추가하며 이전 캐시도 읽기 가능.
표시 정보나 원시 날짜가 없는 이전 캐시는 새로고침 전까지 기존 안내·날짜 문자열 유지.
화면용 번역 정보와 차트의 추가 날짜 필드는 외부 API 응답에서 제외.
레거시 `/v1/usage` 차트의 날짜 `label`은 현지화된 표시 문자열이며 언어 변경 후 새 조회부터 달라질 수 있음.
`/v1/limits`와 CLI의 숫자형 한도·식별자·ISO 8601 시각은 이 날짜 표시와 무관.
기존 Auto 시간 형식은 표시 언어와 별개로 시스템의 12/24시간 설정 준수.

## 검증 기준과 현재 범위

- 최초 실행 English 고정, 세 언어 선택 저장, 다음 실행 반영, 첫 설치 판별 유지 검사 완료.
- 언어별 키·빈 번역·문장 인자 일치와 패키지 내 번역 조회 검사 완료.
- 오류 원문·이전 캐시·CLI·HTTP 응답 계약 회귀 검사 완료.
- 언어 설정·번역 리소스·지표·사용량 추이의 집중 회귀 테스트 통과.
- `make check`의 앱·CLI 빌드와 전체 XCTest·Swift Testing 통과.
- 앱·CLI의 arm64/x86_64 Release 빌드 완료.
- 사이트 정적 검사·빌드, 단위 테스트 96개, E2E 155개 통과.
- 대시보드 행·공유 카드·총 지출 카드의 언어·밀도·테마 조합 60건 렌더링 완료.
  이미지 생성과 언어별 차이를 검사하며 모든 화면의 잘림 검증을 의미하지 않음.

설정 전체·계정 시트·기본 대화상자의 세 언어 배치와 서명된 앱의 실제 재시작 흐름은 미검증.
이 문서의 검증 기록은 커밋·푸시·PR 생성·릴리스 완료를 의미하지 않음.
