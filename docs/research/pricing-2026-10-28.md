# 2026-10-28 모델·요금 확인

확인 기준: 2026-10-28 공식 문서와 `main`의 `ProviderCatalog`·가격 계산 코드.
토큰 요금은 USD / 100만 토큰 기준.
지역·세금·연납·기업 계약에 따른 차이는 별도이며, 구독 가격을 토큰 단가로 환산하지 않음.

## 구조와 적용 범위

SwiftPM 기반 macOS 앱이며, provider별 인증 저장소·사용량 클라이언트·매퍼로 구성.
`ProviderCatalog`에 12개 provider 등록.
Claude·Codex·Cursor·Grok의 토큰 추정 비용은 공통 가격 엔진 사용.
pi 로그의 비용이 없을 때도 이 엔진으로 보완.
나머지는 서버 quota·지출 또는 OpenCode가 저장한 비용을 사용.

가격 우선순위는 보충 파일 → LiteLLM → models.dev.
따라서 하위 카탈로그가 최신이어도 오래된 상위 값 때문에 인하 요율이 반영되지 않을 수 있음.
이번 변경은 공식 자료로 확인한 모델·요금·별칭만 보충 파일에 반영.
제3자 카탈로그를 최신 가격의 근거로 사용하거나 전체 스냅샷을 재생성하지 않음.

## OpenCode의 별도 제약

현재 앱은 로컬 메시지의 `cost`를 합산하고 Go에 5시간 $12·주 $30·월 $60을 일괄 적용.
이는 최신 Go·Go Plus의 모델별 allowance와 다른 이전 계산 방식.
새 API는 청구 비용 `cost`, 포함량 소진 `opencode.allowance`, 결제 출처 `opencode.billing_source`를 구분.
포함량 안의 `cost=0`을 소진량 0으로 해석하면 안 됨.

공식 원본 코드의 stable v1.19.5는 로컬 카탈로그 단가로 메시지 비용을 계산해 저장하며, allowance·결제 출처는 메시지에 저장하지 않음.
v2 개발 코드도 allowance·결제 출처를 사용량 저장 계약에 보존하지 않음.
따라서 로컬 기록만으로 최신 한도·Go Plus 등급을 정확히 복원할 수 없음.
이번 변경에서 임의 상한 교체나 구독 추론을 추가하지 않으며, 이 제한을 [OpenCode 안내](/docs/providers/opencode.md)에 표시.
최신 Go meter 지원에는 별도 quota 데이터 경로와 구독 식별 계약 확인 필요.

## 적용·검증 경계

이번 단가·별칭은 `pricing_v2`·`alias_rules_v2`에 분리하므로 이를 읽는 앱 업데이트 필요.
새 decoder는 v2 가격 우선 병합, v2 별칭 우선 조회 적용.
기존 `pricing` 35개와 `alias_rules` 103개는 그대로 유지해 구버전 앱의 자동 피드 갱신이 Cursor 비용을 바꾸지 않도록 보호.
장문 스키마, Cursor 출처별 조회·모델 묶음, Terra의 Codex 장문 처리도 같은 앱 업데이트에 포함.
v2를 지원하는 앱부터 이후 단가·별칭 수정은 보충 피드 갱신으로 반영 가능.
이 작업은 별도 워크트리의 로컬 변경·검증·커밋까지이며, 가격표 게시·앱 릴리스·운영 실행의 증거는 별개.
