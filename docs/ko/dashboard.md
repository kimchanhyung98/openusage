# 대시보드

메뉴 막대 아이콘을 눌렀을 때 열리는 팝오버입니다. 프로바이더별로 섹션이 나뉘고, 각 섹션에
활성화한 지표가 표시됩니다.

## 첫 실행

새로 설치했다고 해서 OpenUsage가 아는 모든 프로바이더가 켜지는 것은 아닙니다. Claude, Codex, Kimi로
시작한 뒤 Mac에서 인증 정보를 찾을 수 있는 프로바이더(기존 로컬 로그인, 저장된 API 키, 지원되는
환경 변수)를 빠르게 확인해 그 결과만 활성화합니다. 이 정보는 어디에도 전송되지 않습니다. 아무것도
찾지 못하면 Claude/Codex/Kimi 기본 세트를 유지합니다. 대시보드 상단의 일회성 카드가 이 과정을
설명하고 **Customize**(사용자 지정)로 안내합니다. 여기서 원하는 프로바이더를 켜거나 끌 수 있으며,
카드는 ✕ 버튼으로 닫을 때까지 표시됩니다.

이 전체 감지는 완전히 새로 설치했을 때만 실행됩니다. 업데이트는 이미 켜거나 꺼둔 프로바이더를 절대 바꾸지 않습니다. 다만 업데이트로 처음 보는 프로바이더가 추가되면, 해당 프로바이더에 대해서만 동일한 로컬 확인이 한 번 실행되어 실제로 그 도구가 있을 때만 켜집니다. 전체 수명 주기는 [켜져 있는 프로바이더](provider-enablement.md)를 참조하세요.

각 프로바이더 카드는 **항상 표시** 지표로 시작합니다. **필요 시 표시** 선 아래로 옮긴 지표는 카드 안의 캐럿(caret) 뒤에 숨겨집니다 — 클릭하면 캐럿 아래에 펼쳐지고, 다시 클릭하면 접힙니다. 열린 카드는 팝오버를 닫거나 앱을 재시작할 때도 열린 상태가 유지됩니다. 필요 시 표시 지표와 빠른 링크가 모두 없는 프로바이더는 캐럿이 표시되지 않습니다.

카드를 펼치면 숨겨진 지표가 캐럿 아래에 한 열로 표시되어 각 상세 행이 카드 전체 너비를 유지합니다.

프로바이더 카드에는 확장 섹션 하단에 고정된 **빠른 링크 버튼**(Status, Console, Dashboard 등)이 표시될 수도 있으며, 클릭하면 기본 브라우저에서 프로바이더의 페이지가 열립니다. 이 버튼들은 확장 영역의 일부이므로, 캐럿을 접으면 숨겨진 지표와 함께 가려집니다. 버튼은 한 줄에 최대 세 개까지 배치되고, 더 많으면 두 번째 줄로 넘어갑니다.

## 총 지출

활성화된 프로바이더 중 일일 지출을 추적하는 프로바이더가 하나라도 있으면(Claude, Codex, Cursor, Grok, OpenCode), 프로바이더 섹션 위에 카드가 표시됩니다. 제목 옆 드롭다운에서 **Cost**(비용), **Cost/MTok**, **Tokens**(토큰) 중 하나를 선택합니다(기본값은 Cost이며 선택은 재시작 후에도 유지됩니다). 캡슐형 스위처로 기간을 **Today**(오늘), **Yesterday**(어제), **30 Days**(30일) 중에서 바꿀 수 있습니다. 링 차트, 중앙 합계, 순위 범례는 선택한 지표를 따릅니다.

- **Cost** — 각 세그먼트는 해당 프로바이더가 전체 달러에서 차지하는 비중입니다(지출이 가장 큰 프로바이더가 먼저).
- **Cost/MTok** — 각 세그먼트는 해당 프로바이더의 백만 토큰당 달러 요율에 비례해 크기가 정해집니다. 중앙에는 지출과 토큰이 모두 있는 프로바이더들의 혼합 요율이 표시되고, 범례에는 각 프로바이더의 자체 요율이 나열됩니다.
- **Tokens** — 각 세그먼트는 해당 프로바이더가 전체 토큰에서 차지하는 비중입니다.

링 중앙은 항상 짧은 두 줄입니다 — 위에는 간결한 숫자, 아래에는 작은 단위(`$533` / `dollars`, `12.4` / `million`, `$1.37` / `MTok`) — 그래서 Cost/MTok나 큰 합계도 링 안쪽 공간에서 읽기 쉽습니다. Cost 모드는 숫자에 `$`를 유지합니다. 중앙에 마우스를 올리면 정확한 한 줄 수치를 볼 수 있습니다(기여자의 달러가 로컬 추정치일 때는 그 안내도 함께 표시 — Cost와 Cost/MTok에서만). 각 프로바이더는 브랜드에서 가져온 고정 색상(Claude의 테라코타, OpenAI의 초록 등)을 유지하며, 아주 작은 비중이라도 링에 보이는 조각이 남습니다. 선택한 지표에 데이터가 없는 프로바이더는 아예 표시되지 않습니다 — 0으로 계산되는 일은 없습니다. (Customize에서 해당 지출 행을 숨겼더라도 활성화된 프로바이더는 합계에 포함됩니다. OpenRouter의 API 지출 같은 다른 달러 행은 절대 섞이지 않습니다.) 헤더의 공유 아이콘(또는 카드 우클릭)으로 링의 브랜드 PNG를 클립보드에 복사할 수 있으며, 프로바이더 카드 공유와 동일합니다. 헤더에는 합계에 포함되는 프로바이더 이름을 알려주는 작은 ⓘ도 있습니다. 활성 지표에 표시할 내용이 없는 기간은 카드를 숨기는 대신 조용한 빈 상태를 보여줍니다. 카드가 아예 필요 없다면 [설정](settings.md) 상단의 **Show Total Spend**(총 지출 표시)를 끄세요.

## 행

**한도가 있는 지표**(세션, 주간, 상한이 있는 크레딧)는 다음이 포함된 진행 막대를 표시합니다:

- 채움의 색상은 현재 소진 속도를 기준으로 기간이 끝날 때의 상태를 예측한 결과입니다: 최소 10%를 남기고 끝낼 궤도에 있는 동안에는 파랑, 마지막 10% 안쪽에 도달하지만 약간의 여유가 남을 것으로 예상되면 노랑, 초기화 전에 다 쓰거나 여유 없이 한도에 딱 맞게 끝날 것으로 예상되면 빨강입니다. 따라서 절반이 찬 막대라도 소진이 너무 빠르면 이미 빨강이고, 거의 다 쓴 막대라도 초기화까지 순조롭게 진행 중이면 파랑이 유지됩니다. 초기화 시각이 없는 막대(크레딧 잔액 등)와 예측하기에는 너무 이른 새 기간은 대신 현재 사용량 자체로 색이 정해집니다: 80%를 사용하면 노랑, 10% 이하가 남으면 빨강입니다. 색상은 시스템 팔레트에서 가져오므로 라이트/다크 모드와 손쉬운 사용 설정에 맞게 조정되며, Used/Left 토글로 절대 바뀌지 않습니다.
- `52% left`나 `48% used` 같은 헤드라인. **클릭하면** 모든 곳에서 Used와 Left가 전환되고, 마우스를 올리면 반대쪽 수치가 보입니다.
- `Resets in 3h 25m`이나 `Resets today at 6:38 PM` 같은 리셋 라벨. **클릭하면** 모든 곳에서 카운트다운과 정확한 시각이 전환되고, 마우스를 올리면 다른 형식이 보입니다.
- 파란 막대는 기본적으로 추가 표시가 없습니다. **Always Show Pacing**(사용 속도 항상 표시)이 켜져 있으면(설정) 막대에 균등 사용 속도 눈금과 지표 이름 옆에 작은 `~35% left at reset` 메모가 함께 표시됩니다.
- 노란 막대는 지표 이름 옆 오른쪽 정렬로 `~3% spare` 메모를 추가하고, 막대 위에 균등 사용 속도 눈금(기간 전체에 균등하게 소진했다면 사용량이 위치할 지점)도 표시합니다. 그 여유는 항상 최소 1%이며, 여유 없이 끝날 것으로 예상되면 대신 빨강으로 바뀝니다(따라서 노란 막대가 `~0% spare`로 표시되는 일은 없습니다).
- 빨간 막대는 메모 대신 지표 이름 옆에 예상 소진 시각이 있는 빨간 불꽃을 표시합니다 — `Limit in 3h 5m` 또는 `Limit today at 11:49 PM`으로, 리셋 라벨과 같은 카운트다운/정확한 시각 형식을 따릅니다 — 그리고 막대의 균등 사용 속도 눈금은 그대로 표시됩니다. **시각을 클릭하면** 리셋 라벨을 클릭할 때처럼 모든 곳에서 형식이 전환됩니다. 한도에 딱 맞게 끝날 것으로 예상될 때(리셋 전에 다 쓰는 것은 아니지만 여유가 남지 않는 경우)에는 불꽃만 시각 없이 표시됩니다.
- 잔액이 실제로 다 소진되었거나 반올림하면 `0`이 될 만큼 가까워지면(`0% left`나 `$0.00`처럼), 소진 속도가 아무리 완만해 보여도 막대는 빨강을 유지하고 불꽃은 `Limit reached`로 표시됩니다. 눈에 보이게 빈 막대가 더 차분한 색으로 표시되는 일은 없습니다.
- **막대, 여유 메모, 불꽃에 마우스를 올리면** 초기화 시점의 사용 속도 예측(행에 아직 표시되지 않은 그 숫자)을 볼 수 있습니다: 파란 막대는 끝낼 때 남을 것으로 예상되는 여유(`~35% left at reset`), 노란 막대는 여유 메모를 보완하는 사용량(`~92% used at reset`), 빨간 막대는 한도를 얼마나 넘을 것으로 예상되는지(`~12% over limit at reset`, 한도에 딱 맞게 끝날 것으로 예상되면 `~100% used at reset`)입니다. 다 쓴 후에는 `Limit reached`로 표시됩니다.

**한도가 없는 지표**(일일 지출, 잔액)는 `$4.08 spent`나 `1.2M tokens` 같은 한 줄로 표시됩니다. Today / Yesterday / Last 30 Days 행은 비용과 토큰을 합쳐 표시하고(`$4.08 · 1.2M tokens`) Customize에서 켜거나 끌 수 있습니다. 사용량이 없는 날은 오해를 부르는 `$0.00 · 0 tokens` 대신 "No data"(데이터 없음)로 표시됩니다 — 소스를 아예 불러올 수 없을 때와 동일합니다. 큰 숫자는 행을 깔끔하게 유지하기 위해 축약됩니다(`$2.06K`, `1.5B`) — 값에 마우스를 올리면 정확한 수치와 로컬 추정치 같은 출처 안내를 볼 수 있습니다.

Claude, Codex, Cursor, Grok, OpenCode 지출 행에서 값은 마우스를 올리면 은은하게 강조되어 상호작용 가능함을 알립니다. 잠시 마우스를 올려두면 해당 기간의 작은 모델별 내역이 열립니다: 모델 순위 목록으로, 각 항목은 첫 줄에 이름과 지출, 다음 줄에 비중 백분율과 토큰, 그리고 얇은 비중 막대를 보여줍니다. Cursor는 thinking effort별 내보내기 슬러그(예: `claude-opus-4-8-thinking-max`)를 기본 모델 아래로 묶습니다. 긴 꼬리는 **Other**(기타)로 접힙니다 — 상위의 이름 있는 모델을 넘어서거나 해당 기간의 5% 미만인 것들입니다. 어떤 가격 소스로도 가격을 매길 수 없는 모델은 여기(그리고 행의 합계)에 아예 나타나지 않으며, 대신 행의 경고 삼각형이 그 이름을 알려줍니다([가격](pricing.md) 참조).

**Usage Trend**(사용량 추이, Claude, Codex, Cursor, Grok, OpenCode)는 최근 30일간 토큰 사용량의 작은 막대 차트입니다 — 하루에 막대 하나씩, 해당 프로바이더의 지출 행과 같은 소스에서 그립니다(Claude, Codex, Grok, OpenCode는 로컬 로그, Cursor는 사용량 내보내기). **마우스를 올리면** 최고 사용일, 날짜 범위, 소스를 볼 수 있습니다. 기본으로 켜져 있으며, 다른 지표처럼 Customize에서 끄거나 순서를 바꿀 수 있습니다. 메뉴 막대에 별표 지정은 불가능합니다 — 스트립은 차트가 아닌 단일 값을 보여주기 때문입니다.

[iCloud 동기화](icloud-sync.md)가 켜져 있으면 Mac 로컬 프로바이더의 지출 행, 추이, 경고, 모델별 내역이 동기화된 모든 Mac의 데이터로 다시 만들어집니다. Cursor는 내보내기가 이미 계정 전체 기준이므로 변하지 않습니다. 할당량, 요금제, 잔액, 프로바이더 오류는 항상 이 Mac의 새로 고침을 기준으로 합니다.

초기화 시각이 있는 행은 30초마다 갱신되어 새로 고침 사이에도 카운트다운과 사용 속도가 최신 상태로 유지됩니다.

## 계정 선택기

[**Settings → Accounts**(설정 → 계정)](/docs/ko/settings.md)에 Claude 또는 Codex 계정이 두 개 이상 등록되면 해당 관리형 계정의 사용량 보기는 **Claude** 또는 **Codex** 카드 하나를 공유합니다.
카드 헤더의 작은 계정 선택기에는 등록된 관리형 계정만 나오며 카드에 어느 계정의 사용량을 표시할지 고릅니다.
선택기는 보기 전용이며 로그인이나 로그아웃을 실행하거나 새 터미널 세션이 사용할 계정을 바꾸지 않습니다.
터미널 계정 전환은 Settings에서만 실행합니다.
Settings에서 전환을 확정하면 이 선택기와 해당 프로바이더의 메뉴 막대 별이 같은 계정으로 한 번 이동합니다.
비활성 계정의 사용량은 비공개 Keychain 인증 스냅샷에서 읽습니다.
Settings에서 계정을 추가·이름 변경·재로그인·제거하면 선택기가 즉시 갱신됩니다.
커스텀 설정 디렉터리에서 독립적으로 자동 탐색된 Claude 계정은 기존처럼 별도 카드와 이름을 유지합니다.
관련 없는 탐색 카드는 관리형 선택기 안에 숨기지 않습니다.
자동 탐색 로그인과 등록 계정의 identity가 같을 때는 중복 카드 대신 한 번만 표시합니다.
로컬 지출과 추세 로그는 관리형 계정에 귀속되지 않고 해당 설정 홈에 남습니다.
선택기가 비활성 스냅샷 계정을 보여 줄 때 이 행들은 **No data**로 표시될 수 있습니다.

## 우클릭 메뉴

모든 행: **Hide · Star for menu bar / Unstar · Refresh \<provider\> · Customize…**(숨기기 · 메뉴 막대에 별표 지정/해제 · \<프로바이더\> 새로 고침 · 사용자 지정…)(Customize를 선택하면 해당 프로바이더의 지표로 바로 열립니다.)
프로바이더 헤더에는 **Hide \<provider\> · Refresh \<provider\> · Customize… · Share Screenshot**이 있습니다.
Hide는 프로바이더 전체를 끄고 Customize는 다시 켜거나 해당 프로바이더의 지표로 바로 엽니다.
자체 계정 레코드가 있는 Claude 또는 Codex 카드는 **Rename…**(이름 바꾸기)도 표시할 수 있습니다.
계정 identity가 한 번 관찰된 기본 카드도 여기에 포함됩니다.
관리형 계정명은 별도이며 **Settings → Accounts → Manage…**에서 수정합니다.
대시보드 카드 제목은 **Claude** 또는 **Codex**로 유지되고 선택기에 관리형 계정명이 표시됩니다.

## 공유

한 프로바이더의 사용량을 깔끔한 브랜드 PNG로 클립보드에 복사해 채팅, 트윗, 문서에 바로 붙여 넣을 수 있습니다. 두 가지 방법이 있습니다:

- 프로바이더 헤더를 우클릭하고 **Share Screenshot**을 선택합니다.
- 푸터의 **Options**(옵션) 메뉴를 열고 **Share Screenshot** ▸ *\<프로바이더\>*를 선택합니다. 하위 메뉴에는 현재 대시보드에 표시 중인 모든 프로바이더가 나열됩니다.

이미지는 앱의 모습을 담은 가변 높이 PNG입니다 — 상단에 프로바이더 마크와 이름, 현재 보이는 그대로의 지표 행, 하단 중앙에 작은 OpenUsage 마크가 들어갑니다. 라이트/다크 모드를 따릅니다. 카드에 있는 모든 것을 있는 그대로 보여줍니다(숨기거나 흐리게 처리되는 것은 없습니다).

## 푸터

팝오버 하단에 고정된 막대입니다. 왼쪽에는 앱 버전과 "Next update in …"(다음 업데이트까지) 실시간 카운트다운이 있고, 클릭(또는 **⌘R**)하면 바로 새로 고침됩니다. 오른쪽에는 **Options** 메뉴 버튼이 있습니다. 모든 것이 한곳에 모여 있습니다 — **Customize**, **Settings**, **Share Screenshot**(프로바이더 하위 메뉴), **Check for Updates…**, **About OpenUsage**, **Quit OpenUsage**.

## 사용자 지정(Customize)

푸터의 **Options** 메뉴(또는 **Return** 키)로 Customize를 엽니다. 두 단계 화면입니다: 프로바이더 목록, 그다음 개별 프로바이더의 상세 화면.

**프로바이더 목록**에는 모든 프로바이더가 켜기/끄기 스위치, 지표 개수, 상세 화면으로 들어가는 셰브론과 함께 표시됩니다. 프로바이더를 끄면 목록에 회색으로 남습니다 — 지표는 대시보드와 메뉴 막대에서 숨겨지지만 설정은 유지되어 다시 켰을 때 그대로 복원됩니다. 활성화된 프로바이더는 손잡이를 드래그해 순서를 바꿀 수 있고, 행을 탭하면 상세 화면이 열립니다. 새로 설치하면 Mac에서 감지된 프로바이더만 켜진 상태로 시작하고(위의 "첫 실행" 참조), 나머지는 이 목록에서 추가합니다.

프로바이더 **상세 화면**의 상단 막대에는 뒤로 가기 버튼과 프로바이더별 Reset 컨트롤이 있습니다.
표시 중인 프로바이더 id에 자체 계정 레코드가 있을 때만 **Name**(이름) 필드가 나타납니다.
계정 identity가 한 번 관찰된 기본 Claude/Codex 카드도 여기에 포함됩니다.
이 필드는 해당 카드 레코드의 이름을 바꾸며 Settings의 관리형 계정명과는 별개입니다.
그다음 **항상 표시**와 **필요 시 표시**라는 두 개의 지표 섹션이 나옵니다.
각 지표 행에는 드래그 손잡이, 이름, 메뉴 막대용 별표, 켜기/끄기 스위치가 있습니다.
지표를 다른 섹션이나 그 섹션의 행 위로 드래그하면 항상 표시와 필요 시 표시 사이를 이동합니다.
빈 섹션은 점선의 **Drag metrics here**(지표를 여기로 드래그) 대상을 보여줍니다.
프로바이더당 최대 두 개의 지표에 별표를 지정할 수 있습니다.
OpenRouter와 Z.ai는 **API Key** 섹션도 표시하며 해당 프로바이더의 키를 추가, 교체, 표시, 삭제할 수 있습니다.

드래그 순서 바꾸기는 대시보드에서도 바로 동작합니다 — 같은 프로바이더 안에서 행을 드래그하거나, 카드가 열린 상태에서 캐럿 경계를 넘겨 드래그하거나, 프로바이더 헤더를 드래그해 섹션 순서를 바꿀 수 있습니다. Force Touch 트랙패드에서는 드래그한 항목이 새 자리에 들어갈 때마다 가벼운 탭 촉감이 느껴집니다.

기본 리셋 레이아웃은 이 fork의 owner 설정을 따릅니다. Claude는 Session, Weekly, Fable을, Codex는 Session과 Weekly를, Kimi는 Session과 Weekly를 항상 표시로 둡니다. Claude와 Codex의 Usage Trend 및 선택적 한도, 리셋 상세, 지출 기록 행은 필요 시 표시로 시작합니다. 기본으로 꺼진 선택적 행도 언제든 활성화할 수 있습니다.

의도하지 않은 변경을 했나요? **⌘Z**를 눌러 실행 취소하세요 — 팝오버 어디서든(대시보드와 Customize 모두) 동작하며 최근 사용자 지정 변경을 하나씩 되돌립니다: 지표 숨기기/표시, 지표 또는 프로바이더 전체의 순서 바꾸기, 별표 지정/해제, 구분선을 넘나드는 지표 이동 모두 실행 취소됩니다. 각 단계는 정확히 이전 배치로 복원합니다. 실행 취소는 세션 단위입니다(재시작하면 새로 시작되며), 리셋하면 지워집니다.

OpenUsage에 새 기본 지표가 추가되면 기존 레이아웃에 한 번 반영됩니다. 끄면 꺼진 상태가 유지됩니다. 프로바이더의 **Reset** 버튼(상세 화면 오른쪽 상단)은 해당 프로바이더의 기본 지표, 순서, 메뉴 막대 별표, 필요 시 표시로 시작하는 지표를 복원하지만 다른 프로바이더와 프로바이더 순서는 건드리지 않습니다. **Reset All Customization**(모든 사용자 지정 초기화) 버튼(프로바이더 목록 오른쪽 상단)은 모든 프로바이더에 대해 동일한 작업을 한꺼번에 수행하고, 기본 프로바이더 순서를 복원하며, 설치된 도구를 다시 감지합니다 — 첫 실행처럼 Mac에 설정된 도구에 해당하는 프로바이더만 정확히 다시 켭니다([켜져 있는 프로바이더](provider-enablement.md) 참조). 전체 레이아웃을 지우고 프로바이더를 다시 감지하며 실행 취소할 수 없으므로, 먼저 확인을 요청합니다.

## 키보드

| 키 | 동작 |
|---|---|
| Return | 대시보드에서 Customize 열기, 프로바이더 상세에서 프로바이더 목록으로 돌아가기, 프로바이더 목록이나 설정에서 대시보드로 돌아가기 |
| Esc | 프로바이더 상세에서 프로바이더 목록으로 돌아가기, 프로바이더 목록이나 설정에서 대시보드로 돌아가기, 대시보드에서 팝오버 닫기 |
| ⌘Z | 마지막 사용자 지정 변경 실행 취소(앱 전체, 반복하면 계속 되돌아감) |
| ⌘R | 대시보드 또는 설정에서 지금 새로 고침(캐시를 건너뜀) |
| ⌘, | 설정 열기/닫기(팝오버 안) |

전역 단축키(설정에서 등록)로 어디서든 팝오버를 토글할 수 있습니다.

## 닫기

팝오버를 닫으면 탐색 상태가 초기화됩니다: 스크롤 위치가 맨 위로 돌아가고 Customize / 설정이 닫힙니다. 프로바이더 카드는 확장 캐럿이 열려 있었는지 기억합니다.
