# 활성화되는 프로바이더

OpenUsage가 처음에 어떤 프로바이더를 켜는지, 업데이트로 새 프로바이더가 추가될 때 어떻게
처리하는지를 설명합니다. 핵심 규칙은 하나입니다. **사용자가 직접 바꾼 토글은 항상 우선하며,
업데이트가 덮어쓰지 않습니다.**

## 첫 설치

새로 설치한 앱은 알고 있는 모든 프로바이더를 한꺼번에 켜지 않습니다. Claude, Codex, Cursor를
기본으로 켠 뒤, Mac에서 인증 정보를 찾을 수 있는 프로바이더(기존 로컬 로그인, 저장된 API 키,
지원되는 환경 변수)를 빠르게 확인해 그 결과만 활성화합니다. 이 확인은 네트워크로 정보를 보내지
않습니다. 모든 프로바이더를 동시에 확인하므로 전체 시간은 각 확인 시간의 합이 아니라 가장 오래
걸린 하나의 확인 시간에 가깝습니다. 아무것도 찾지 못하면 Claude/Codex/Cursor 기본 세트를 유지합니다.
감지된 프로바이더는 즉시 데이터를 가져오므로 다음 예약 새로 고침까지 기다리지 않아도 됩니다.
대시보드에서의 표시 방식은 [대시보드 § 첫 실행](dashboard.md#첫-실행)을 참고하세요.

## 업데이트로 새 프로바이더가 추가될 때

나중에 추가된 프로바이더에도 같은 감지가 적용됩니다. 업데이트 후 첫 실행에서 OpenUsage는
현재 앱에 포함된 프로바이더와 이 설치가 이전에 알고 있던 프로바이더를 비교합니다. 새로 발견된
각 프로바이더에 대해 로컬에서만 인증 정보를 확인합니다:

- **로컬에서 인증 정보 사용 가능** → 프로바이더가 켜지고 대시보드에 표시됩니다.
- **인증 정보 없음** → 꺼진 상태로 유지됩니다. 나중에 **Customize**(사용자화)에서 언제든 켤 수 있습니다.

이 확인은 **프로바이더마다 한 번**만 수행됩니다. 그 뒤부터는 사용자가 직접 관리합니다. 한 번
끈 프로바이더를 업데이트가 다시 켜지 않으며, 나중에 해당 도구를 설치해도 자동으로 켜지지 않습니다.
필요할 때 Customize에서 직접 켜면 됩니다.

## 선택은 항상 유지됩니다

Customize에서 설정한 모든 것 — 프로바이더 온/오프, 지표 레이아웃, 메뉴 막대 별표 — 은 업데이트 후에도 그대로 유지됩니다. 업데이트가 변경할 수 있는 유일한 것은 한 번도 본 적 없는 프로바이더를 **켜는** 것뿐이며, 해당 도구가 실제로 설치되어 있을 때만 그렇게 합니다.

유일한 예외는 Customize 프로바이더 목록 상단의 **Reset All Customization**(모든 사용자화 초기화)
버튼입니다. 사용자가 초기화를 요청한 것이므로, 첫 실행과 같은 로컬 인증 정보 감지를 다시 실행해
Mac에서 인증 정보를 찾은 프로바이더만 켭니다(아무것도 찾지 못하면 Claude/Codex/Cursor를 켭니다).
따라서 켜 두었던 프로바이더가 꺼질 수도 있고, 꺼 두었던 프로바이더가 다시 켜질 수도 있습니다.
실행 전에는 확인을 요청합니다. 지표 초기화에 관한 내용은 [대시보드](dashboard.md)를 참고하세요.

## 동작 방식(궁금한 분을 위해)

앱은 세 개의 작은 목록을 설정에 저장합니다:

- **활성화된 프로바이더** — 현재 켜져 있는 프로바이더입니다. 대시보드와 메뉴 막대가 참조하는 기준입니다.
- **알려진 프로바이더** — 이 설치가 지금까지 본 모든 프로바이더. 이 덕분에 "이번 업데이트의 신규"와 "사용자가 끈 것"을 구분할 수 있습니다. 활성화 목록에는 없지만 알려진 목록에는 있는 프로바이더는 의도적인 선택이므로 그대로 둡니다. *둘 다* 없는 프로바이더만 인증 정보를 확인하며, 확인과 함께 즉시 알려진 것으로 표시되어 확인이 반복되지 않습니다.
- 각 프로바이더는 가볍고 로컬 전용인 인증 정보 확인(`hasLocalCredentials()`)을 구현합니다. 일반 새로 고침이 읽는 것과 같은 파일, 키체인 항목, 저장된 키, 환경 변수를 확인하며 네트워크는 사용하지 않습니다.

(첫 실행 감지가 생기기 이전의) 오래된 설치는 모든 프로바이더가 켜진 상태로 시작했고 *꺼진* 것만 저장했습니다. 일회성 설정 마이그레이션이 이를 위의 목록들로 변환하며, 켜짐/꺼짐 프로바이더는 이전과 정확히 동일합니다. 마이그레이션되는 실행에서 눈에 보이는 변화는 없고, 이후부터는 동일한 신규 프로바이더 감지에 합류할 뿐입니다.
