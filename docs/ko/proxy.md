# 프록시

OpenUsage는 모든 프로바이더 요청을 선택적으로 프록시를 거쳐 보낼 수 있습니다.

- 지원: `socks5://`, `http://`, `https://`
- 설정 파일: `~/.openusage/config.json`
- 기본값: 꺼짐
- UI: 없음 — 파일에서만 설정

## 설정 파일

```json
{
  "proxy": {
    "enabled": true,
    "url": "socks5://127.0.0.1:10808"
  }
}
```

인증이 필요한 프록시는 URL에 사용자 이름과 비밀번호를 포함합니다:

```json
{
  "proxy": {
    "enabled": true,
    "url": "http://user:pass@proxy.example.com:8080"
  }
}
```

URL에 포트가 없으면 스킴의 기본 포트가 적용됩니다(socks5 → 1080, http → 80, https → 443).

## 동작

- 설정은 시작 시 한 번만 읽습니다. **파일을 변경한 후에는 OpenUsage를 재시작하세요**.
- `localhost`, `127.0.0.1`, `::1`은 항상 프록시를 우회합니다([로컬 HTTP API](local-http-api.md)는 영향을 받지 않습니다).
- 설정 파일이 없거나, 프록시가 비활성화되어 있거나, 설정이 잘못되었거나, 파일을 읽을 수 없으면 프록시를 사용하지 않습니다.

## 적용 범위

일일 [모델 가격 정보](pricing.md) 새로 고침을 포함해 앱이 보내는 프로바이더 HTTP 요청에 적용됩니다. 시스템 전체의 프록시 설정을 바꾸는 기능은 아닙니다.
