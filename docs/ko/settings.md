# 설정

설정은 별도 창이 아니라 팝오버 안에 표시됩니다. 팝오버가 열린 상태에서 ⌘,를 누르거나 푸터의
**Options**(옵션) 메뉴에서 열 수 있으며, 메뉴 막대 아이콘을 우클릭한 뒤 Settings를 선택해도 됩니다.
대시보드가 옆으로 이동하고 설정 화면이 나타나며, 왼쪽 위에는 뒤로 가기 버튼이 있습니다. 이 버튼,
⌘,, 단축키, Esc로 돌아갈 수 있습니다. Esc는 먼저 대시보드로 돌아가고, 한 번 더 누르면 팝오버를 닫습니다.

## 일반

| 설정 | 옵션 | 동작 |
|---|---|---|
| Show Total Spend (총 지출 표시) | 켜기/끄기 | 프로바이더 전체를 합산한 [총 지출](dashboard.md#총-지출) 카드를 대시보드 상단에 표시할지 정합니다. 기본값은 켜기이며, 지출을 추적하는 프로바이더(Claude, Codex, Cursor, Grok, OpenCode)가 하나 이상 활성화되어 있으면 카드가 나타납니다. |
| Launch at Login (로그인 시 실행) | 켜기/끄기 | 앱을 로그인 항목으로 등록합니다. 로그인 항목 목록은 macOS의 시스템 레지스트리를 기준으로 합니다. |
| Global Shortcut (전역 단축키) | 단축키 기록 | 어디서든 팝오버를 열고 닫는 전역 단축키입니다. 필드를 클릭하고 키 조합을 누르면 기록되며, ⓧ를 누르면 지워지고 비활성화됩니다. |

**레거시(0.7 이전) 에디션에서 업그레이드하는 경우:** 예전 에디션은 자체 런처 파일로 로그인 시 실행을 관리했으며, 앱을 덮어써서 업데이트해도 이 파일이 남아 있었습니다. 이 파일 때문에 로그인할 때 앱이 한 번 더 실행될 수 있었고, 시스템 설정 → 로그인 항목에는 OpenUsage 대신 서명 회사 이름("SUNSTORY LLC")으로 표시되었습니다. 현재 앱은 실행할 때 해당 파일이 OpenUsage를 가리키는 것이 확인된 경우에만 자동으로 제거합니다. 이제 로그인 시에는 Launch at Login 토글로 관리되는 앱 하나만 실행됩니다.

## iCloud 동기화

**Sync Across Macs**(Mac 간 동기화)는 기본적으로 꺼져 있습니다. 켜면 앱의 비공개 iCloud 컨테이너를
통해 정규화된 OpenUsage 기록을 공유하고, 같은 iCloud 계정으로 로그인한 여러 Mac의 로컬 토큰과
지출을 합산합니다. 설정에는 5분 쓰기 주기와 각 Mac의 상대적인 **Updated**(업데이트) 시각이 표시되며,
iCloud를 사용할 수 없음, 읽는 중, 쓰는 중, 파일 형식 오류 같은 상태도 알려 줍니다. 포함되는 데이터와
합산 값이 사용되는 화면은 [iCloud 동기화](icloud-sync.md)를 참고하세요.

## 화면

| 설정 | 옵션 | 동작 |
|---|---|---|
| Icon Style(아이콘 스타일) | Text / Bars | 별표한 지표를 메뉴 막대에 렌더링하는 방식입니다. 기본값은 Bars입니다. [메뉴 막대](menu-bar.md)를 참조하세요. |
| Theme(테마) | System / Light / Dark | 팝오버에 적용되는 앱 전체 화면 모양 재정의입니다. |
| Density (밀도) | Default / Compact | 새로 설치하면 Compact가 기본값입니다. Default는 여백이 넉넉하고 Compact는 정보를 더 촘촘히 보여 줍니다. Compact에서는 글자가 한 단계 작아지고, 행과 프로바이더 섹션 사이가 좁아지며, Customize / Settings 행도 함께 줄어듭니다. 두 모드 모두 연속된 한 줄 지표(Today / Yesterday / …) 사이가 붙고 Compact에서 더 촘촘해집니다. |
| Time Format(시간 형식) | Auto / 12-hour / 24-hour | 정확한 시각을 표시하는 방식입니다(예: "Resets today at 6:38 PM"(오늘 오후 6:38에 리셋) 대 "18:38"). 기본값은 24-hour이며 Auto는 시스템을 따릅니다. |
| Increase Transparency (투명도 높이기) | 끄기 / 켜기 | 끄기(기본값)는 팝오버를 불투명한 패널로 유지합니다. 켜면 팝오버가 반투명해져 데스크톱이 비쳐 보이지만, 숫자와 Options 컨트롤은 적응형 반투명 표면 위에서 읽기 쉽게 유지됩니다. macOS 손쉬운 사용 설정인 **Reduce Transparency**(투명도 감소)나 **Increase Contrast**(대비 증가)가 켜져 있으면 자동으로 일시 중지되며, 그 이유를 안내합니다. |

## 사용량 표시

| 설정 | 옵션 | 동작 |
|---|---|---|
| Show Usage As (사용량 표시 방식) | Used / Left | 상한이 있는 지표를 "48% used"(48% 사용)로 표시할지 "52% left"(52% 남음)로 표시할지 정합니다. 기본값은 Used이며 헤드라인을 클릭하는 것과 같은 토글입니다. |
| Reset Times (초기화 시각 표시) | Countdown / Exact time | "Resets in 3h 25m"(3시간 25분 후 초기화)과 "Resets today at 6:38 PM" 중 하나를 선택합니다. 기본값은 Exact Time이며 초기화 레이블을 클릭하는 것과 같은 토글입니다. |
| Always Show Pacing (사용 속도 항상 표시) | 끄기 / 켜기 | 켜기(기본값)는 초기화 기간이 있는 모든 지표에 사용 속도를 표시합니다. 정상적으로 진행 중인 행에는 예상치("~33% left at reset"(초기화 시 약 33% 남음))와, 같은 속도로 사용했다면 현재 도달했을 위치를 보여 주는 눈금이 추가됩니다. 끄면 한도에 가까워지거나 초과할 때만 표시합니다. 초기화 기간이 없는 지표에는 표시할 사용 속도가 없습니다. |

## 알림

지표의 잔량이 줄거나 사용 속도가 나빠지면 OpenUsage가 macOS 알림으로 알려 줍니다. 할당량이
한도에 가까워지는지 확인하려고 팝오버를 계속 열어 둘 필요가 없습니다. 팝오버가 닫혀 있어도
앱이 메뉴 막대에서 실행 중이면 알림이 동작합니다.

| 설정 | 옵션 | 동작 |
|---|---|---|
| Almost Out (거의 소진) | 켜기 / 끄기 | 초기화 기간이 없는 잔액을 포함해, 지표의 잔량이 10% 아래로 떨어지면 알립니다. |
| Cutting It Close (한도에 근접) | 켜기 / 끄기 | 이번 기간이 끝날 때 잔량이 거의 없고 한도에 가까울 것으로 예상되면 알립니다. |
| Will Run Out (곧 소진) | 켜기 / 끄기 | 초기화 전에 지표가 모두 소진될 것으로 예상되면 알립니다. |

알림은 새로운 임계점을 넘거나 사용 속도가 악화될 때 한 번 발생합니다. 같은 상태가 이어지는 동안에는
중복을 제거하므로 매 새로 고침마다 반복되지 않습니다. 앱을 실행했을 때 이미 좋지 않은 상태인 할당량은
알림 없이 기준선으로 기록합니다. 이후 회복했다가 다시 악화되면 알림이 다시 활성화되고, 새로운
초기화 기간이 시작되면 초기화 관련 기록도 지워집니다. **Almost Out**은 잔량만 기준으로 하므로
초기화 기간이 없는 상한 잔액에도 동작합니다. **Cutting It Close**와 **Will Run Out**은 초기화 기간과
사용 속도 정보가 있어야 합니다. 데이터를 읽을 수 없는 지표는 알리지 않습니다. 세 트리거를 모두 끄면
모든 알림이 꺼집니다. 여러 알림이 동시에 발생하면 하나의 그룹 배너로 묶입니다.

세 알림은 모두 기본적으로 꺼져 있습니다. 처음 하나를 켜면 OpenUsage가 알림 권한을 요청합니다.
권한을 거절하거나 나중에 시스템 설정에서 OpenUsage 알림을 끄면 알림 섹션 제목에 경고 표시가 나타나고,
토글 아래에 "Open System Settings"(시스템 설정 열기) 버튼이 표시됩니다. 알림 제목은 알림 이름이며,
부제목에는 프로바이더와 지표, 본문에는 평이한 설명이 들어갑니다. 알림을 클릭하면 대시보드가 열린
팝오버가 나타납니다.

## 개인정보

| 설정 | 옵션 | 동작 |
|---|---|---|
| Hide From Screen Share (화면 공유 중 숨기기) | 켜기 / 끄기 | 켜기(기본값)는 화면을 공유하거나 녹화하는 동안 메뉴 막대 스트립을 OpenUsage 아이콘과 워드마크로 바꾸고, 캡처가 끝나는 즉시 별표 지표를 복원합니다. [메뉴 막대](menu-bar.md#화면-공유-중-사용량-숨기기)를 참고하세요. |
| Share Anonymous Usage (익명 사용량 공유) | 켜기 / 끄기 | 기본값은 끄기입니다. 켜면 익명의 일일 사용량 요약을 공유하며 계정 정보, 인증 정보, 사용량 값은 포함되지 않습니다. 전송되는 정보와 전송되지 않는 정보는 [개인정보 및 사용 데이터](privacy.md)를 참고하세요. |

## 고급

| 설정 | 옵션 | 동작 |
|---|---|---|
| Log Level (로그 레벨) | Error / Warning / Info / Debug | 앱이 로그 파일에 기록하는 상세 수준입니다. 기본값은 Info이며 재시작 후에도 유지됩니다. 문제를 재현할 때는 Debug로 올리세요. 즉시 적용됩니다. |
| Copy Log Path (로그 경로 복사) | 버튼 | 로그 파일 경로(`~/Library/Logs/OpenUsage/OpenUsage.log`)를 클립보드에 복사합니다. |
| Reveal in Finder (Finder에서 보기) | 버튼 | 로그 파일을 선택한 Finder 창을 엽니다. |

전체 동작(서브시스템 태그, 파일 크기 상한, 비밀 값이 절대 기록되지 않는다는 보장)은 [로깅](logging.md)을 참조하세요.

## 업데이트

업데이트 섹션은 서명된 업데이트 피드가 포함된 공식 패키지 빌드에만 나타납니다. 로컬 개발자 빌드에는 표시되지 않습니다.

| 설정 | 옵션 | 동작 |
|---|---|---|
| Update Automatically(자동 업데이트) | 켜기 / 끄기 | Sparkle이 백그라운드에서 업데이트를 확인할지 여부입니다. 꺼져 있어도 수동으로 확인할 수 있습니다. |
| Beta Updates(베타 업데이트) | 켜기 / 끄기 | 받을 수 있는 업데이트에 프리릴리스 빌드를 추가합니다. 안정 릴리스는 어느 쪽이든 계속 받을 수 있습니다. |
| Check for Updates…(업데이트 확인…) | 버튼 | 수동 업데이트 확인을 시작하고 Sparkle의 업데이트 창을 엽니다. |

대시보드 배너, 채널, 서명 검증에 대해서는 [업데이트](updates.md)를 참조하세요.

## 버전

앱 버전은 팝오버 푸터에 표시됩니다.

설정은 업데이트 후에도 유지됩니다. 레이아웃, 별표, 환경 설정, 메뉴 막대 단축키가 모두 그대로입니다.
업데이트로 설정 저장 방식이 바뀌면 앱이 실행될 때 데이터를 새 형식으로 바꾸며, 중간 버전을 몇 개
건너뛰었더라도 필요한 변환을 순서대로 적용합니다. 아무것도 초기화되지 않습니다. (초기 베타에서는
업데이트할 때마다 모든 설정이 지워졌지만 이제는 그렇지 않습니다.)

어떤 프로바이더를 켜 두었는지도 업데이트 후에도 유지되며, 사용자의 선택이 덮어씌워지는 일은 없습니다. 새로 설치한 경우에는 Mac에 설치된 AI 도구를 감지해 시작 세트를 정합니다([대시보드 § 첫 실행](dashboard.md#첫-실행) 참조). 업데이트에 처음 보는 프로바이더가 포함되면, 그 프로바이더에 대해서만 같은 로컬 감지가 한 번 실행되어 실제로 해당 도구가 있을 때만 켜집니다. 이미 결정해 둔 나머지는 모두 설정한 그대로 유지됩니다. [활성화된 프로바이더](provider-enablement.md)를 참조하세요.
