# 업데이트

OpenUsage는 Mac 앱에서 널리 사용하는 업데이트 프레임워크인 [Sparkle](https://sparkle-project.org)를
통해 최신 상태를 유지합니다. 업데이트는 OpenUsage의 릴리스 피드에서 내려받고 설치 전에
검증하므로, 변조되지 않은 정식 빌드만 설치됩니다.

## 동작 방식

- **자동 확인.** 앱이 백그라운드에서 약 1시간마다 새 버전을 확인합니다. 새 버전을 찾으면 다른 앱 뒤에 창을 띄우는 대신 팝오버 상단에 **Update Available**(업데이트 있음) 배너를 표시합니다. **Install Update**(업데이트 설치)를 클릭하면 릴리스 노트, 다운로드, 설치를 포함한 업데이트 창이 앞에 열립니다. 배너의 닫기 버튼을 누르면 다음 확인 때까지 숨겨집니다.
- **수동 확인.** 언제든지 **Settings → Updates**(설정 → 업데이트)에서 **Check for Updates…**(업데이트 확인…)를 누르세요. 수동 확인과 배너를 통한 설치 모두 Sparkle 창을 열기 전에 OpenUsage를 앞으로 가져오므로, 창이 다른 앱 뒤에 묻히지 않습니다. 평소에는 메뉴 막대 앱이라 Dock 아이콘이 없지만, 업데이트하는 동안만 잠시 표시한 뒤 다시 숨깁니다.
- **끄기.** **Settings → Updates**의 **Update Automatically**(자동 업데이트)를 끄면 백그라운드 확인이 중단됩니다. 수동 확인은 계속할 수 있습니다.

## 베타 업데이트

**Settings → Updates → Beta Updates**(설정 → 업데이트 → 베타 업데이트)를 켜면 정식 출시 전에
배포되는 프리릴리스 빌드도 받을 수 있습니다. 끄면 안정 버전만 받게 되며, 다음 안정 릴리스가
현재 버전을 따라잡을 때까지 지금 설치된 버전을 유지합니다.

안정 릴리스는 베타 설정과 관계없이 모두에게 제공됩니다. 베타 옵션은 여기에 프리릴리스 빌드를
*추가*하는 기능입니다.

## 업데이트 출처

업데이트 빌드는 OpenUsage의 GitHub 릴리스에 게시되고, 사용 가능한 버전 목록("appcast")은
`https://openusage.chanhyung.kim/appcast.xml`에서 제공됩니다. 각 다운로드는 Apple 공증과
OpenUsage 자체 서명으로 이중 검증되며, 어느 쪽이든 일치하지 않으면 앱이 거부합니다. 이 기능은
공식 서명 릴리스 빌드에서만 제공되고 로컬 개발자 빌드에는 없습니다.
