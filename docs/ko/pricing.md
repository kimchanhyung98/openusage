# 모델 가격

OpenUsage가 토큰 수를 지출 타일(Claude, Codex, Cursor, Grok)의 추정 달러 금액으로 환산하는
방식을 설명합니다. OpenRouter와 OpenCode는 예외입니다. OpenRouter는 API가 청구 금액을 직접
보고하고, OpenCode는 로컬 로그에 메시지별 비용을 기록하므로 이 문서의 추정 방식이 적용되지 않습니다.

## 가격의 출처

가격은 세 가지 출처에서 가져오며, 같은 모델이 여러 출처에 있으면 우선순위가 높은 출처의
값을 사용합니다:

1. **OpenUsage 가격 보충 파일** — 이 저장소에서 관리하고 GitHub Pages에 게시하는 작은 JSON 파일입니다. 공개 카탈로그에 없는 모델(`auto`, `composer-*` 같은 Cursor 전용 모델), fast 변형 배율, 프로바이더 로그/CSV 슬러그를 카탈로그 키로 연결하는 별칭 규칙을 다룹니다.
2. **LiteLLM** — 커뮤니티가 관리하는 `model_prices_and_context_window.json`으로, API 가격이 있는 대부분의 모델을 포함합니다.
3. **models.dev** — LiteLLM이 놓친 모델(예: 새로 출시된 모델이나 일부 특수 모델)을 보완합니다.

앱은 세 출처의 스냅샷을 함께 포함해 배포하므로 오프라인이나 첫 실행에서도 가격을 계산할 수
있습니다. 실행 중에는 각 출처를 약 한 시간마다 다시 가져오고(ETag 재검증 사용),
`~/Library/Application Support/OpenUsage/pricing/`에 캐시합니다. 가격 정보를 새로 고치는 동안에도
사용량 스캔은 멈추지 않으며, 스캔은 그 시점에 이미 확보한 가장 최신 가격으로 계산됩니다.

보충 파일은 `main`에 병합될 때 GitHub Pages에 게시되므로, 가격 수정은 앱 업데이트 없이도
약 한 시간 안에 설치된 앱에 반영됩니다.

## 모델 이름을 가격표에 연결하는 방법

로그와 CSV의 모델 이름은 카탈로그 키와 정확히 일치하지 않는 경우가 많습니다. 그래서 보충 파일의
별칭 규칙, 키의 정확한 일치, fast 변형 처리(`-fast` 접미사를 기본 모델로 연결한 뒤 fast 배율 적용),
유사 매칭 순서로 확인합니다. 유사 매칭에서는 프로바이더 접두사(`anthropic/`, `xai/` 등), 날짜
접미사(`claude-sonnet-4` ↔ `claude-sonnet-4-20250514`), 구분자 차이(`grok-4-3` ↔ `grok-4.3`)를
고려합니다. 명시적인 가격이나 모델별 배율이 없는 fast 변형은 표준 속도 가격을 몰래 적용하지 않고
가격을 계산할 수 없는 상태로 남깁니다.

어떤 출처에서도 가격을 찾지 못한 모델은 지출 수치에서 제외됩니다. 일부 토큰을 빠뜨린 달러
금액과 전체 토큰 수를 함께 보여 주면 오해를 부를 수 있기 때문입니다. 대신 해당 타일의 경고
삼각형에 가격을 찾지 못한 모델이 표시되므로 수치가 불완전한 이유를 알 수 있습니다. 그날 가격을
계산할 수 있는 모델이 하나도 없으면 "No data"(데이터 없음)로 표시됩니다.

## 추정치에 포함되는 것

비용은 각 사용 이벤트의 네 가지 토큰 묶음(일반 입력, 캐시 쓰기, 캐시 읽기, 출력)에 모델의
백만 토큰당 요금을 적용해 계산합니다. 1시간 캐시 쓰기 가격, 긴 컨텍스트 구간, fast 변형 배율도
반영합니다. Claude 로그는 모델명을 그대로 둔 채 요청의 `speed` 필드로 fast 모드를 표시할 수
있으므로, 기본 모델 항목에도 해당 배율을 적용합니다. 대부분의 카탈로그 구간은 프롬프트 토큰 200k 초과부터 높은 요금이 적용되고,
지원되는 GPT-5.4, GPT-5.5, GPT-5.6 Codex 모델은 입력 토큰 272k 초과부터 전환됩니다. 어느 경우든
높은 요금은 요청 전체에 적용됩니다. 공개된 캐시 할인이 있으면 사용하고, 출처가 할인을 제공하지
않으면 Codex 캐시 입력에는 전체 입력 요금을 적용합니다. Cursor 내보내기는 여러 요청을 한 행에
합치므로, 그중 하나가 한도를 넘었다고 추측하지 않고 일반 요금을 사용합니다. Claude 로그에
`costUSD`가 명시되어 있으면 그 값을 그대로 사용합니다. Claude advisor 사용량처럼 전달받은 비용이
없는 중첩 사용량은 advisor 모델의 토큰으로 별도 계산합니다. 결과는 청구서가 아니라 API 요금 기준의
추정 가치입니다. 구독 요금제는 토큰별로 청구되지 않습니다.

## 개인정보 보호

가격 새로 고침은 세 개의 공개 가격 목록(`raw.githubusercontent.com`, `models.dev`, 이 저장소의
GitHub Pages)을 내려받습니다. 이 요청에는 사용량이나 로그 데이터가 포함되지 않으며, 사용량 정보는
Mac 밖으로 나가지 않습니다.

## 유지 관리자 노트

- **보충 파일 변경**(새 Cursor 네이티브 모델, 가격 수정, 새 별칭): `Sources/OpenUsage/Resources/pricing_supplement.json`을 편집하고, [Cursor 모델 및 가격](https://cursor.com/docs/models-and-pricing.md)에서 항목을 동기화한 뒤 `updated_at`을 갱신하세요. `main`에 병합되면 `.github/workflows/pricing-supplement.yml`이 이를 gh-pages에 게시하며, 설치된 앱은 약 한 시간 안에 이를 받아옵니다. 번들 사본은 첫 실행을 위해 다음 릴리스에 포함됩니다. **pricing-update skill**(`.agents/skills/pricing-update/`)은 에이전트가 전체 동기화 과정(Cursor 페이지 가져오기, diff, 편집, 검증, PR 열기)을 수행하도록 안내합니다.
- **번들 스냅샷**(`pricing_litellm_snapshot.json`, `pricing_models_dev_snapshot.json`): 가끔(예: 릴리스 전) `script/update_pricing_snapshots.sh`로 재생성하세요. 오래되어도 무해합니다. 런타임 가져오기가 이를 덮어씁니다.
