# 개인정보 및 사용 데이터

OpenUsage는 앱이 어떻게 사용되는지 파악하고 문제를 찾는 데 도움이 되도록 **익명** 사용 데이터를 공유할 수 있습니다. 기본적으로 꺼져 있으며 **Settings → Privacy → Share Anonymous Usage**(설정 → 개인정보 → 익명 사용 데이터 공유)에서 언제든 켤 수 있습니다.

## 공유되는 항목

공유가 켜져 있으면 OpenUsage는 두 종류의 작은 일일 요약을 보냅니다. 하루에 앱 사용 이벤트 하나,
그리고 그날 새로 고침된 각 프로바이더에 대해 최대 하나의 프로바이더 새로 고침 이벤트를 보냅니다:

- **앱 사용** — 오늘 앱을 사용했는지 여부, 앱 및 macOS 버전, 켜 둔 프로바이더와 지표, 메뉴 막대에 고정했거나 "show more"(더 보기) 캐럿 뒤에 숨긴 지표입니다. 사용자나 계정과 연결되지 않은 임의 ID를 사용해 개인을 식별하지 않고 일일 활성 사용자 수를 셉니다.
- **프로바이더 새로 고침** — 프로바이더별 성공·실패 횟수, 발생한 오류의 **종류**(예: "not logged in", "network", HTTP 상태 그룹), 수동 새로 고침 횟수입니다.

또한 **크래시**를 보고하여, 앱이 예기치 않게 종료되게 만드는 버그를 찾아 고칠 수 있습니다:

- **크래시 리포트** — OpenUsage가 크래시되면 리포트를 저장했다가 다음에 앱을 열 때 전송합니다. 기술적 스택 트레이스(크래시 당시 *OpenUsage 자체 코드*의 어느 부분이 실행 중이었는지)와 앱 및 macOS 버전이 포함됩니다. 계정 정보, 인증 정보, 사용량 값은 포함되지 않으며 앱의 어느 부분에서 크래시가 발생했는지만 담깁니다.

## 절대 공유되지 않는 항목

- 계정 정보, 이름, 이메일, 인증 정보는 공유되지 않습니다.
- 실제 사용량 **값**(지출 금액, 토큰 수, 한도)은 공유되지 않습니다.
- 오류 **메시지**나 파일 경로는 공유되지 않으며, 대략적인 오류 범주의 횟수만 공유됩니다.
- 토글이 꺼져 있는 동안에는 아무것도 전송되지 않습니다.

## 이 Mac에 저장된 인증 정보

OpenUsage는 주로 프로바이더 도구가 이미 Mac에 보관하고 있는 인증 정보를 읽습니다. 사용자가 제공한
API 키를 쓰거나 갱신된 인증 정보를 저장할 때는 파일이 원자적으로 교체되고 해당 macOS 계정으로
제한됩니다(소유자 읽기/쓰기만 가능). Antigravity의 수명이 짧은 갱신 토큰 캐시는 단방향 지문으로
현재 키체인 로그인에 연결되며, 갱신 인증 정보 자체는 복사되지 않습니다. 이 캐시는 로그아웃 후,
계정 변경 후, 또는 키체인에 접근할 수 없는 동안에는 사용되지 않습니다.

Claude Desktop 접근은 철저히 읽기 전용입니다. OpenUsage는 Desktop의 현재 액세스 토큰을 복호화하기
위해 macOS에 `Claude Safe Storage` 키체인 항목 사용 권한을 요청할 수 있습니다. Desktop의
자동으로 교체되는 갱신 토큰은 절대 사용하지 않으며, Desktop의 설정, 쿠키, 키체인 데이터를 절대
수정하지 않습니다.

관리형 계정 전환([**Settings → Accounts**(설정 → 계정)](/docs/ko/settings.md))은 `OpenUsage Account Authentication`으로 시작하는 서비스 이름으로 계정마다 인증 스냅샷 하나를 macOS 키체인에 보관합니다.
이 스냅샷을 사용해 다시 전환할 때 이전 로그인을 복원합니다.
각 스냅샷에는 해당 계정의 인증 파일 내용이 담기며 사용자의 macOS 로그인 키체인에만 보관되고 어디에도 전송되지 않습니다.
추가 계정의 공식 로그인은 `~/Library/Application Support/OpenUsage/AccountSignIn/<provider>/<account-id>/` 아래의 앱 소유 작업 공간에서 실행됩니다.
작업 공간 디렉터리는 `0700`, credential 파일은 `0600` 권한을 사용합니다.
계정을 제거하면 먼저 작업 공간을 삭제하고 그다음 Keychain 스냅샷을 삭제합니다.
어느 삭제든 실패하면 다시 시도할 수 있도록 계정 등록을 유지합니다.
`~/.claude`와 `~/.codex` 데이터는 절대 이동하거나 삭제하지 않습니다.
전환을 확정하면 `~/.zshrc` 또는 `~/.config/fish/config.fish`에 작은 `claude`/`codex` 함수도 갱신합니다.
함수는 `>>> OpenUsage` 주석 마커로 감싸며 이 마커 블록을 삭제하면 함수가 제거됩니다.

관리형 계정명, 선택 계정 상태, 로그인 준비 상태와 인증 스냅샷은 이 Mac에만 남고 iCloud 동기화에 포함되지 않습니다.
iCloud 대상은 정규화된 사용량 히스토리뿐입니다.
관리형 공유 홈 히스토리는 현재 선택된 계정이 아니라 프로바이더 family 전체 합계로 동기화합니다.

## 기타 네트워크 요청

벤더 도구가 수행하는 프로바이더 API 호출 외에, OpenUsage는 공개 [모델 가격 목록](pricing.md)을 약 한 시간에 한 번(`raw.githubusercontent.com`, `models.dev`, 이 프로젝트의 GitHub Pages에서) 내려받습니다. 공개 데이터만 다운로드하며 사용량, 로그, 계정 정보를 전혀 보내지 않습니다. 이 요청은 Share Anonymous Usage 설정과 관계없이 실행됩니다. 지출 타일은 로컬 CLI 로그로 Mac에서만 계산되며 로그 데이터는 Mac 밖으로 나가지 않습니다.

재실행할 때마다 변경되지 않은 Claude, Codex, pi 로그를 다시 읽지 않기 위해, OpenUsage는 파싱된
사용 이벤트를 `~/Library/Application Support/OpenUsage/log-scan-cache/`에 보관합니다. 이 레코드에는
로컬 합계에 필요한 사용량 메타데이터(프로바이더가 이미 기록한 이벤트별 비용 포함)가 들어 있지만,
원시 JSONL 줄이나 대화 텍스트는 포함되지 않습니다. 이 데이터는 해당 macOS 계정에만 보관되며 PostHog,
프로바이더, iCloud 어디에도 절대 전송되지 않습니다. 오래된 소스 파일 레코드는 스캔 범위가
전진하면서 버려지고, 35일 동안 사용되지 않은 identity 캐시는 제거됩니다. OpenUsage의 가격 책정
엔진은 캐시를 읽은 뒤에 실행되므로, 계산된 집계와 합계는 이 캐시에 저장되지 않습니다.

[iCloud Sync](icloud-sync.md)를 명시적으로 켜면, OpenUsage는 정규화된 일일 토큰, 지출, 모델별
합계를 비공개 iCloud 컨테이너에 기록하여 사용자의 Mac들이 하나의 결합 요약을 보여줄 수 있게
합니다. 인증 정보, 계정 한도, 프로바이더 응답, 원시 로그는 절대 기록되지 않습니다. 이는 익명
사용 데이터 공유와는 별개입니다. iCloud Sync는 기본값이 꺼져 있고 사용자의 iCloud 계정을
사용하는 반면, 애널리틱스 토글은 PostHog 이벤트를 제어합니다.

## 동작 방식

- 데이터는 완전히 익명입니다. OpenUsage는 분석 서비스에서 사용자를 식별하지 않으며 사용자 프로필을 만들지 않습니다.
- 크래시 리포트는 **같은** Share Anonymous Usage 스위치를 사용합니다. 이 설정을 끄면 크래시 보고도 꺼지며 별도의 설정은 없습니다. 꺼져 있는 동안에는 크래시 리포트를 기록하거나 보내지 않습니다.
- 횟수는 로컬에서 집계되어 일일 요약으로 전송되므로, 앱의 일반적인 5분 새로 고침이 네트워크 호출 폭주로 이어지지 않습니다.
- 사용자의 선택과 익명 ID는 앱의 나머지 설정과 분리되어 저장되므로, 설정 마이그레이션이나 업데이트가 공유를 다시 활성화하거나 ID를 변경하지 않습니다.

## 공유 설정

**Settings → Privacy**를 열고 **Share Anonymous Usage**를 켜면 공유에 참여합니다. 끄면 공유가 즉시 중단됩니다.
