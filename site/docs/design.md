# 랜딩 페이지 디자인

밝은 배경, 절제된 타이포, 넓은 여백, 앱 형태의 그래픽을 사용하는 페이지.
페이지는 밝은 외관 유지, 조작 가능한 앱 미리보기는 자체 Theme 설정 반영.

## 시각 토큰

| 토큰 | 값 |
|---|---|
| 배경 / 글자 | `#fbfbf8` / `#3c2e2a` |
| 강조 / 글자 강조 | `#2b7fff` / `#0f62e6` |
| 배경 워시 | `#e6eff9` |
| 서체 | Apple SF Pro (macOS/iOS 시스템 네이티브) 우선, 비-Apple 환경은 셀프호스팅 구글 Noto Sans KR |
| 시스템 폴백 | Segoe UI, Roboto, Apple SD Gothic Neo, Malgun Gothic |
| 첫 화면 / 섹션 제목 | `clamp(22px, 3.1vw, 46px)` / `18px` |
| 내비게이션 높이 | `74px` |
| 앱 미리보기 폭 / 최대 높이 | `320px` / 데스크톱 `560px`, 모바일 `300–420px` |

폰트 파일 옆에 라이선스 동봉.
provider 마크는 빌드 시 네이티브 앱 리소스에서 조회.
앱 그래픽은 일관된 예시 데이터를 사용하는 HTML/CSS 재현이며 개인 계정 스크린샷 아님.

## 배치

데스크톱 첫 화면은 한 줄 헤드라인·소개 문구·다운로드 링크와 앱 미리보기를 별도 열에 배치.
지원 OS·CPU와 한국어·영어·일본어 지원 표시.
미리보기 아래 예시 데이터 고지.
720–899px 구간의 헤드라인은 `2.8vw`로 줄여 배정된 열 안에 한 줄 유지.
720px 미만에서는 세로로 쌓고, 앱의 원래 폭보다 좁으면 미리보기 전체 축소.
내비게이션은 워드마크와 링크 두 개를 한 줄로 유지.
지원 서비스는 아이콘·이름의 정적 그리드 사용.

주요 기능 영역은 내비게이션 아래 공간을 채움.
텍스트 탭 7개로 하나의 맥북 장면 조작.
메뉴 막대·대시보드·사용량 통계·초기화 예측·한도 안내선·계정·연동 순서.
두 줄 설명과 필요한 조건 안내는 넓은 화면에서 옆, 좁은 세로 화면에서 아래에 배치.
기능을 바꿔도 섹션 높이·페이지 위치 유지.
마지막 화면은 다운로드와 푸터가 한 뷰포트를 나눠 사용. 카피라이트 아래 출처 고지, 옆에 소셜 링크 배치.

| 화면 폭 | 컨테이너 | 그리드 간격 |
|---|---|---|
| 1280px 이상 | 화면 폭에서 12vw 제외, 최대 1440px | 40px |
| 900–1279px | 화면 폭에서 8vw 제외, 최대 1440px | 32px |
| 600–899px | 화면 폭에서 48px 제외 | 24px |
| 600px 미만 | 화면 폭에서 40px 제외 | 16px |

## 모션과 입력

- 페이지 입력은 섹션 경계에서 이동. 화면보다 긴 섹션은 내용 끝까지 스크롤한 뒤 이동.
- 조작 가능한 앱 위의 입력은 상단·하단·고정 영역을 포함해 앱 내부에서만 처리.
- 주요 기능은 7개 단계를 모두 거친 뒤 섹션 이탈.
- 새 기능 선택 시 이전 애니메이션 취소, Escape로 현재 단계의 최종 상태 표시.
- 계정 추가는 일반 시연의 절반 속도로 재생.
- 동작 줄이기에서는 커서·카메라 애니메이션 없이 최종 상태 표시.
- 메뉴는 키보드 초점과 화면 경계 유지, 기간 선택은 방향키 지원.

## 2026년 10월 갱신 기준

2026-10-26 운영 사이트·게시 이력과 앱 소스 비교.
사이트는 9월 12일 도입한 화면을 유지한 채 일부 문구·언어 설정만 갱신된 상태.
운영 다운로드는 `v0.14.0`, 앱 미리보기 푸터는 `0.11.1`로 서로 다른 버전 표시.
이번 갱신은 `v0.14.0`과 현재 저장소의 공개 UI 계약 기준.

| 항목 | 기존 사이트 | 반영 내용 |
|---|---|---|
| 첫 화면 | 제목과 대시보드 | 기능 요약·지원 언어·다운로드·기능 이동 링크, 모바일 패널 높이 조정 |
| Reset Watch | 값 없는 일반 사용량 막대 | 예측 확률·커뮤니티 투표율·예측 시각, 별도 기능 시연 |
| 리셋 크레딧 | `2 resets` 문구 | 사용 가능 개수와 읽기 전용 만료 목록 팝오버 |
| Soft Limit | 설정·시연 없음 | 임계값·기간 설정과 안내선, 자동 취소 미지원 명시 |
| 알림 | 세 할당량 알림 | 독립적인 Codex Reset Watch 선택 추가 |
| 계정 | 조회 선택기·설정 전환 | 웹 기본 개별 카드로 Codex 두 계정 표시, 카드 우클릭의 확인 후 전환 추가 |
| 언어 | 선택값만 저장하고 영어 유지 | 한국어·일본어 선택 시 전체 데모·기능 시연에 즉시 적용, 재시작 불필요 |
| 푸터 | `0.11.1`, 정적 새로고침 문구 | `0.14.0`, 새로고침 동작 안내 버튼 |

동작 근거: [대시보드](/docs/dashboard.md), [설정](/docs/settings.md), [Codex](/docs/providers/codex.md), `Views/WidgetRowView.swift`, `Views/RateLimitResetsDetail.swift`, `Views/WidgetGroupedListView.swift`.
초기화권 개수에 포인터를 올리면 만료 목록 팝오버 표시.
웹에서는 클릭·키보드로도 열 수 있으며, 카드 높이를 늘리지 않는 읽기 전용 목록으로 재현.
실제 앱의 초기화권 사용·인증·알림 발송·초기화 요청은 재현 범위에서 제외.
사용량 추이는 앱과 같은 파란색 막대, 폭 90–150px, 막대 간격 1px 기준.
바로가기 버튼은 밝은 테마에서도 배경을 구분할 수 있도록 테마 색 적용.
